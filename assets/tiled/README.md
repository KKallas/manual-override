# Photon Yard — editable Tiled level

## Z pixel first map

The simplified Z-inspired level is available at
`levels/z-pixel-first-map.tmj`. It uses the versioned `z-pixel-v2-*` tilesets,
four left-side approaches, two far-right 180-degree merges, two returns to one
central mega tower, sixteen square tag spots, and eight force-field candidates.
See `levels/z-pixel-first-map.README.md` for its routing and regeneration
contract.

Open `photon-crane.tiled-project` in Tiled, then open `levels/photon-yard.tmj`.
The map uses Tiled's JSON formats (`.tmj` and `.tsj`) so it can be diffed,
generated by tools, and fine-tuned visually by a designer.

## What is editable

- **Style Reference (hidden)** — the generated 1672×941 inspirational artwork.
  It is locked and invisible by default; it is not part of the rendered map.
- **Ground Modules** — eighteen editable 320×320 component objects cover the
  canvas using the generated concrete, service-panel, and conduit textures.
- **Road Modules** — fifty-six editable recessed road objects form four
  right-side approaches, separate far-left upper/lower turns, and two central
  returns. Their dark beds and inset rim shadows read as channels below ground.
  They snap at 160 pixels but render at 164×164 to hide component-edge cracks.
- **Industrial Border and Props** — separately movable generated machinery,
  vents, lights, pipes, crates, and storage components.
- **Enemy Path Graph** — two upper and two lower right-side approaches travel
  left, circle around separate top/bottom back turns, then use two return
  polylines toward the central core.
- **Path Nodes** — four spawns, two approach merges, two return entries, and the
  core.
- **Tower Sockets (16)** — six Purple-only, six Green-only, and four shared
  sockets. The shared positions are lower-value by design.
- **Player Reach Zones** — hidden by default to keep the artwork readable. Turn
  the layer on when moving sockets so exclusive/shared access remains clear.
- **Force Field Gate Hints** — legal vertical endpoint pairs. A gate is created
  at runtime only while both referenced sockets contain active towers.
- **Gameplay Zones** — Photon synchronization, core damage, and camera bounds.
  This diagnostic layer is hidden by default so the full-map camera bounds do
  not tint the normal editor preview.
- **Starter Structures** — one Purple machine gun and one Green flamethrower.
- **Core and Crane Components** — editable instances from the generated sprite
  pack, including the opposing upper-right and lower-left crane assemblies.
- **Enemy Preview Markers** — an optional hidden staging layer. These objects
  do not spawn runtime enemies.

## Component palettes

The `tilesets/` folder contains collection-of-images tilesets. Placement
components reference normalized 320×320 derivatives under
`assets/game-art/normalized/`; original generated files remain unchanged:

- objectives and socket states
- structures and upgrade/damage states
- crane parts and hero cores
- roads and ground pieces
- environment props
- force-field and weapon effects
- light enemies, heavy enemies, and the boss

Objects can be dragged from these palettes into any object layer and scaled or
rotated without altering the original sprite files.

Roads use generated style guidance from
`previews/sunken-road-style-reference.png` and deterministic transparent
derivatives under `assets/game-art/normalized-sunken/roads/`. Run
`tools/build_sunken_road_assets.py` after normalizing source components and
before rebuilding the level.

`GroundModule` and `RoadModule` objects include grid coordinates, original
asset IDs, normalized size, and road-port metadata. The map is therefore
assembled from components rather than a flattened visual background.

## Runtime contract

The map is intentionally data-oriented. Game code should read objects by their
Tiled class and custom properties rather than by layer order.

- `PathNode.node_id` is the stable node key.
- `PathEdge.from_node` and `to_node` are Tiled object references.
- `PathEdge.road_width` is the traversable corridor width in design pixels.
- `TowerSocket.socket_id` is stable; the Tiled object ID is not.
- `TowerSocket.owner` is `green`, `purple`, or `shared`.
- `GateHint.socket_a` / `socket_b` are object references and
  `requires_active_towers` must remain true.
- The map hard-caps active enemies at 1,000 and placed structures at 8.
- `photon-yard.waves.json` contains the 20-wave contract configuration and uses
  a pressure bank when the active-enemy cap is reached.

If a socket is deleted and recreated, reconnect any gate or starter-structure
object references in Tiled's Properties panel.

## Regeneration and checks

Run from the project root:

```sh
/Users/kaur/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  .agents/skills/tiled-modular-map-builder/scripts/normalize_components.py \
  --manifest assets/game-art/asset-pack.json \
  --output assets/game-art/normalized --size 320

/Users/kaur/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  tools/build_sunken_road_assets.py

/Users/kaur/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  tools/build_tiled_level.py

python3 .agents/skills/tiled-modular-map-builder/scripts/validate_modular_map.py \
  assets/tiled/levels/photon-yard.tmj \
  --report assets/tiled/modular-validation-report.json
```

The script recreates the project, map, tilesets, wave configuration, and
`validation-report.json`. It verifies all referenced PNGs, the 16-socket rule,
the four-to-two path topology, spawn-to-core reachability, reach ownership,
gate endpoints, and the 1,000-enemy / 8-structure limits. If Pillow is present,
it also refreshes `previews/photon-yard-editor-preview.png`; otherwise only the
preview step is skipped.

The installed Tiled 1.12.2 command-line tools can also perform a native check:

```sh
/Applications/Tiled.app/Contents/MacOS/Tiled \
  --project assets/tiled/photon-crane.tiled-project \
  --resolve-types-and-properties --export-map \
  assets/tiled/levels/photon-yard.tmj /tmp/photon-yard-roundtrip.tmj

/Applications/Tiled.app/Contents/MacOS/tmxrasterizer --anti-aliasing \
  assets/tiled/levels/photon-yard.tmj \
  assets/tiled/previews/photon-yard-tiled-render.png
```

Edit the source data in `tools/build_tiled_level.py` only when the level should
remain generator-controlled. For normal human tuning, edit the `.tmj` in Tiled
and do not rerun the generator afterward unless those changes have first been
copied back into the script.
