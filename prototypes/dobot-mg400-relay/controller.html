Connection

Robot must be in API mode — see docs/operations/dobot-api-mode.md. Clear clears the robot error AND un-latches the E-STOP. Enable starts the follower in the current holder's mode (or joint).

Stop

Latches E-STOP, stops the follower and cuts servo power. Recover with Clear → Enable. Keyboard: Esc.
