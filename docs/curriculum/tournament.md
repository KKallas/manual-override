# Final Tournament

The course ends with a tournament that brings the three classes together:
spatial control, strategy, and a learning agent — competing head-to-head on the
shared screen.

## Goals

- Give students a motivating finale and a clear way to show what they learned.
- Compare **human-tuned** play against **agent-driven** play, and mixtures of the
  two.
- Reinforce sportsmanship, safety, and reflection.

## Formats

Pick what fits your group size and time:

| Format | Who plays | What it highlights |
|--------|-----------|--------------------|
| **Human vs. Human** | Two students on sliders/assisted control | Class 1–2 skill: planes + strategy |
| **Human vs. Agent** | Student vs. a Class-3 trained agent | Can intuition beat a learned policy? |
| **Agent vs. Agent** | Two student-trained agents | Whose training/strategy generalizes? |
| **Relay / team** | Teams rotate control of one robot | Communication & shared strategy |

## Structure

- **Seeding round** — short matches to rank players/agents.
- **Bracket** — single or double elimination depending on time.
- **Final** — best-of-three on the standard match profile.

Use the standard match parameters from [../game-design.md](../game-design.md)
unless you announce changes up front.

## Roles

- **Referee/operator** — runs the server and referee GUI, starts/stops matches,
  owns the E-stop, resolves disputes.
- **Players** — control a robot via the agreed mode for their match.
- **Spectators/commentators** — optional; reading the live score and contested-zone
  action makes good narration.

## Fairness & safety

- Announce the control mode and parameters before each match; keep them constant
  within a bracket.
- Same physical setup and calibration for both sides.
- Safety rules from [../operations/SETUP.md](../operations/SETUP.md) apply
  throughout — hands clear of the work zone, E-stop within reach.

## Reflection (the real finale)

After the trophy, run a short debrief:

- Where did human intuition win? Where did the learned agent win?
- What strategy mattered most — aiming, node rotation, the contested zone?
- If you had one more class, what would you teach the agent next?

This ties the competition back to the learning goals: planes, strategy, and a
loop that learns.
